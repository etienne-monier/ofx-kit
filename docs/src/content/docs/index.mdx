`ofx-kit` parses bank statements into strongly typed Rust structures. It
supports the existing credit-card and investment statement subsets as well as
OFX 1.x SGML and OFX 2.x XML.

The library is pure: it performs no file I/O and uses exact decimal values for
financial amounts.
